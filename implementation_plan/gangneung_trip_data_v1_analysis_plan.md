# 강릉캠프 트립 데이터 분석 계획 (gangneung_trip_data_v1)

이 계획은 강릉캠프의 최근 킥보드 매출 감소 및 16세 미만 자전거 탑승량 증가 원인을 파악하기 위한 심층 분석을 수행합니다.

## User Review Required

> [!IMPORTANT]
> - **매출/대당매출 기준**: 킥보드 대당매출(Revenue per Asset) 산정 시 `allocated_revenue / allocated_assigned_count` 공식을 사용합니다. 
> - **이상치 탐지 기준**: 킥보드 대당매출 감소율이 **19% 초과**인 소지역을 특이점(Anomaly)으로 간주하여 별도 차트를 생성합니다.
> - **제외 대상**: '외국인' 데이터는 인구통계학적 세그먼트 분석에서 제외합니다.
> - **결과물 저장 위치**: 분석 결과표(엑셀) 및 시각화 차트(PNG)는 `/results/gangneung_trip_data_v1/` 폴더에 저장할 예정입니다.

## Proposed Changes

#### 분석 모듈 1: 인구통계학적 세그먼트별 YoY 분석
- 성별, 연령대, 가입지역 기준 전체 YoY 증감률 계산.
- 특히 **'16세 미만'** 세그먼트의 기기별(자전거/킥보드) 트립 수 및 매출(allocated_revenue) YoY 변화 집중 분석.

#### 분석 모듈 2: 월별 기기/연령별 트립 수 추이 시각화
- 2025년과 2026년 동기간(1~5월) 월별 트립 수 집계.
- **라인 차트**: 기기별(Bicycle, Scooter)로 연령대별 트립 수 추이 시각화.

#### 분석 모듈 3: 소지역별 전체 및 16세 미만 YoY 분석
- 전체 사용자 대상 소지역별 YoY (트립수, 매출, 대당매출).
- '16세 미만' 세그먼트 대상 소지역별 YoY.

#### 분석 모듈 4: 25년/26년 기기별 세그먼트 파이 차트
- 기기별(Bicycle, Scooter) 연령대별 트립수 비중 파이 차트 생성 (2025년 vs 2026년 비교).

#### 분석 모듈 5: 특이점(Anomaly) 탐지 및 시각화
- 소지역별 킥보드 대당 매출 전년비 감소율 계산.
- **감소율 > 19%** 인 소지역 식별 및 해당 지역들의 트립/매출 변화 바 차트 생성.
