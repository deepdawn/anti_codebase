## 프로젝트 개요

### 주요 목표
- 예상 물량 예측
- 고객의 구매 확률 분석
- 구매 결정에 영향을 미치는 주요 특성(feature) 발굴

### 프로젝트 진행 순서
1. 데이터 수집 및 전처리
2. 탐색적 데이터 분석 (EDA)
3. 특성 공학 및 선택
4. 모델 개발 및 학습
5. 모델 평가 및 해석
6. 결과 도출 및 활용 방안

### 기대 효과
- 물량 예측 정확도 향상으로 재고 관리 최적화
- 고객 구매 확률 기반 마케팅 전략 수립
- 데이터 기반 의사결정 체계 구축

## 데이터 분석 방법론

### 1. 데이터 수집
- **내부 데이터**: 판매 기록, 고객 정보, 제품 카탈로그 등
- **외부 데이터**: 시장 동향, 경쟁사 정보, 계절성 요인 등
- **데이터 통합**: 다양한 소스의 데이터를 단일 분석 환경으로 통합

### 2. 데이터 전처리
- **결측치 처리**: 평균, 중앙값, 최빈값 또는 예측 모델 기반 대체
- **이상치 감지 및 처리**: Z-점수, IQR 방법, 이상치 제거 또는 변환
- **정규화/표준화**: Min-Max 스케일링, Z-score 정규화
- **인코딩**: 범주형 변수의 원-핫 인코딩, 레이블 인코딩

### 3. 탐색적 데이터 분석 (EDA)
- **단변량 분석**: 각 변수의 분포, 기술 통계량 파악
- **이변량 분석**: 변수 간 상관관계, 인과관계 탐색
- **시계열 분석**: 시간에 따른 패턴, 추세, 계절성 파악
- **시각화 기법**: 히스토그램, 산점도, 히트맵, 박스플롯 등

### 4. 특성 공학
- **파생 변수 생성**: 기존 변수 조합을 통한 새로운 인사이트 도출
- **차원 축소**: PCA, t-SNE, UMAP 등을 통한 고차원 데이터 단순화
- **특성 선택**: 상관관계 분석, 중요도 평가를 통한 핵심 변수 선별

### 5. 가설 검정
- **통계적 검정**: t-검정, 카이제곱 검정, ANOVA 등
- **A/B 테스팅**: 실험군과 대조군 비교를 통한 인과관계 검증
- **이중차분법(Difference-in-Differences, DID)**: 자연 실험의 인과관계 추정을 위한 방법

#### 이중차분법(DID) 상세 설명
- **기본 원리**: 정책/처치의 영향을 받는 그룹(처치군)과 영향을 받지 않는 그룹(대조군)의 시간에 따른 결과 변화 차이를 비교
- **주요 가정**:
  - 평행 추세 가정(Parallel Trends): 처치가 없었다면 처치군과 대조군은 유사한 추세를 보였을 것
  - SUTVA(Stable Unit Treatment Value Assumption): 한 개체의 처치가 다른 개체의 결과에 영향을 미치지 않음
- **구현 방법**:
  ```
  Y = β₀ + β₁·Treatment + β₂·Post + β₃·(Treatment×Post) + ε
  ```
  - Treatment: 처치군 여부(1=처치군, 0=대조군)
  - Post: 처치 후 기간 여부(1=처치 후, 0=처치 전)
  - β₃: 처치 효과 추정치(DID 계수)
- **활용 사례**: 정책 평가, 마케팅 효과 분석, 자연재해/경제 충격 영향 분석

### 6. 분석 결과 해석
- **비즈니스 맥락화**: 통계적 발견을 실질적 비즈니스 인사이트로 변환
- **액션 아이템 도출**: 분석 결과 기반의 구체적 행동 계획 수립

### 7. 데이터 파이프라인 구축
- **자동화**: 반복적인 데이터 수집 및 전처리 과정 자동화
- **모니터링**: 데이터 품질 및 분석 결과의 지속적 모니터링

## ML 모델링 접근법

### 1. 문제 정의
- **회귀 문제**: 예상 물량 예측
- **분류 문제**: 고객 구매 확률 예측
- **특성 중요도**: 구매 결정 요인 식별

### 2. 데이터 분할
- **훈련 세트(Train Set)**: 모델 학습용 (보통 전체 데이터의 70%)
- **검증 세트(Validation Set)**: 하이퍼파라미터 튜닝용 (15%)
- **테스트 세트(Test Set)**: 최종 모델 평가용 (15%)
- **시계열 데이터**: 시간적 순서 고려한 분할 방법 적용

### 3. 모델 선택
#### 회귀 모델 (예상 물량 예측)
- **선형 회귀(Linear Regression)**: 기본 모델, 해석력 높음
- **RandomForest, XGBoost**: 비선형 관계 포착 우수
- **시계열 모델**: ARIMA, Prophet, LSTM 등

#### 분류 모델 (구매 확률 예측)
- **로지스틱 회귀(Logistic Regression)**: 기본 모델, 해석력 높음
- **트리 기반 앙상블**: RandomForest, GradientBoosting
- **고급 모델**: LightGBM, CatBoost

### 4. 하이퍼파라미터 튜닝
- **그리드 서치(Grid Search)**: 모든 조합 탐색
- **랜덤 서치(Random Search)**: 무작위 조합 탐색
- **베이지안 최적화**: 효율적인 파라미터 공간 탐색
- **교차 검증(Cross-Validation)**: K-Fold, 시간 기반 교차 검증

### 5. 모델 평가
#### 회귀 모델 지표
- **MSE, RMSE**: 예측값과 실제값 차이의 제곱 평균(제곱근)
- **MAE**: 절대 오차 평균
- **R²**: 모델이 설명하는 분산 비율

#### 분류 모델 지표
- **정확도(Accuracy)**: 전체 중 정확히 분류된 비율
- **정밀도(Precision)**: 양성 예측 중 실제 양성 비율
- **재현율(Recall)**: 실제 양성 중 양성으로 예측된 비율
- **F1 Score**: 정밀도와 재현율의 조화평균
- **ROC-AUC**: 분류 성능 곡선 아래 면적

### 6. 모델 해석
- **특성 중요도(Feature Importance)**: 모델 내 변수별 중요도
- **SHAP 값**: 개별 예측에 대한 변수 기여도
- **부분 의존성 플롯(PDP)**: 특정 변수의 영향 시각화

### 7. 모델 배포 및 모니터링
- **모델 저장 및 로드**: pickle, joblib, ONNX 등
- **성능 모니터링**: 시간에 따른 모델 성능 변화 추적
- **모델 업데이트 전략**: 정기적 재학습, 온라인 학습 등
