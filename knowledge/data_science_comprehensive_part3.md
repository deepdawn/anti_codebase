# 데이터 사이언스 종합 문서 (Part 3)

## 주요 특성(Feature) 발굴

### 1. 특성 발굴의 중요성
- **마케팅 효율화**: 구매 결정에 영향력이 큰 요소에 집중
- **제품 개선**: 고객 선호도가 높은 속성 식별
- **고객 경험 개선**: 만족도에 영향을 미치는 핵심 접점 파악
- **비즈니스 인사이트**: 데이터 기반 의사결정 강화

### 2. 특성 발굴 방법론

#### 통계적 접근법
- **상관관계 분석**: 종속 변수와의 선형 관계 강도 측정
- **카이제곱 검정**: 범주형 변수 간 관계성 평가
- **ANOVA**: 그룹 간 차이 유의성 검정
- **정보 이득(Information Gain)**: 엔트로피 감소 기반 중요도 평가

#### 모델 기반 접근법
- **선형/로지스틱 회귀 계수**: 변수별 영향도 직접 해석
- **트리 기반 중요도**: 불순도 감소 또는 분할 빈도 기반
- **순열 중요도(Permutation Importance)**: 변수 셔플링 후 성능 감소 측정
- **Shapley 값(SHAP)**: 게임 이론 기반의 변수 기여도 계산

#### 차원 축소 기법
- **주성분 분석(PCA)**: 분산 기여도가 높은 성분 식별
- **인자 분석(Factor Analysis)**: 잠재 요인 도출
- **t-SNE/UMAP**: 비선형 특징 공간 시각화
- **오토인코더**: 딥러닝 기반 표현 학습

### 3. 도메인별 핵심 특성 후보

#### 고객 속성 관련 특성
- **인구통계학적 요소**: 연령대, 성별, 소득수준, 거주지역
- **라이프스타일**: 관심사, 취미, 가치관
- **고객 여정 단계**: 인지, 고려, 구매, 유지 단계
- **기술 활용도**: 디지털 성숙도, 기기 사용 패턴

#### 제품/서비스 관련 특성
- **가격 요소**: 절대 가격, 경쟁사 대비 상대가격, 할인율
- **품질 속성**: 내구성, 성능, 디자인, 사용 편의성
- **브랜드 요소**: 인지도, 평판, 신뢰도, 친밀감
- **제품 다양성**: 옵션, 커스터마이징 가능성

#### 구매 행동 관련 특성
- **구매 이력**: 과거 구매 빈도, 금액, 최근성(RFM)
- **탐색 행동**: 웹사이트 체류 시간, 페이지 뷰, 검색 키워드
- **장바구니 활동**: 장바구니 추가/삭제, 포기율
- **디바이스/채널**: 접속 기기, 유입 경로, 구매 채널

### 4. 특성 평가 및 선택

#### 평가 기준
- **예측력**: 목표 변수 예측에 대한 기여도
- **안정성**: 시간 경과에 따른 특성 값의 일관성
- **해석 가능성**: 비즈니스 관점에서의 이해 용이성
- **획득 용이성**: 데이터 수집 비용 및 어려움

#### 특성 선택 전략
- **필터 방법**: 통계적 측정값 기반 사전 선택
- **래퍼 방법**: 모델 성능 기반 최적 조합 탐색
- **임베디드 방법**: 모델 학습 과정에서 자동 선택
- **앙상블 선택**: 다양한 방법 결과 종합

### 5. 특성 해석 및 활용

#### 해석 방법론
- **부분 의존성 플롯(PDP)**: 특성값 변화에 따른 예측 변화
- **개별 조건부 기대값(ICE)**: 개별 데이터에 대한 특성 영향
- **LIME(Local Interpretable Model-agnostic Explanations)**: 국소적 모델 해석
- **글로벌 중요도 vs 로컬 중요도**: 전체 및 개별 사례별 분석

#### 비즈니스 활용 방안
- **세그먼테이션 고도화**: 주요 특성 기반 고객 그룹 재정의
- **제품 개발 가이드**: 핵심 속성 강화 방향성 제시
- **타겟팅 정교화**: 고객별 구매 결정 요인 기반 접근
- **커뮤니케이션 최적화**: 핵심 특성 중심의 메시지 개발

## 실험설계 및 인과관계 분석

### 1. A/B 테스트 (웹/앱 환경)

#### 기본 원리
- **정의**: 두 가지 버전(A: 대조군, B: 실험군)을 무작위로 사용자에게 노출하여 성과 지표를 비교
- **목적**: 변경 사항이 목표 지표에 미치는 인과적 영향 측정
- **적용 영역**: 웹사이트, 모바일 앱, 마케팅 캠페인, 제품 기능

#### 구현 단계
1. **지표 설정**: 전환율, 체류 시간, ARPU 등 측정할 핵심 지표 정의
2. **표본 크기 결정**: 통계적 유의성을 위한 필요 샘플 수 계산 (파워 분석)
3. **무작위 할당**: 사용자를 대조군/실험군에 무작위 배정
4. **테스트 실행**: 충분한 기간 동안 테스트 유지
5. **결과 분석**: 통계적 검정을 통한 차이의 유의성 평가

#### 통계적 분석 방법
- **t-검정**: 두 그룹 평균의 차이 검정
- **Z-검정**: 비율 차이 검정 (전환율 등)
- **신뢰구간**: 효과 크기의 범위 추정
- **베이지안 분석**: 사전 확률을 고려한 효과 추정

### 2. 이중차분법 (Difference-in-Differences, DID)

#### 기본 원리
- **정의**: 실험군과 대조군의 시간에 따른 결과 변화의 차이를 비교
- **목적**: 자연 실험 상황에서의 인과 효과 측정
- **적용 영역**: 정책 평가, 지역 기반 마케팅, 자연 재해 영향 분석

#### 수학적 모델
```
Y = β₀ + β₁·Treatment + β₂·Post + β₃·(Treatment×Post) + ε
```
- **β₃**: 처치 효과 추정치 (핵심 계수)

#### 주요 가정
- **평행 추세**: 처치가 없었다면 두 그룹은 유사한 추세를 보였을 것
- **SUTVA**: 한 단위의 처치가 다른 단위의 결과에 영향을 미치지 않음
- **안정성**: 구성 효과 없음 (그룹 구성이 시간에 따라 변하지 않음)

### 3. 회귀 불연속 설계 (Regression Discontinuity Design, RDD)

#### 기본 원리
- **정의**: 처치 할당이 특정 임계값을 기준으로 결정될 때의 분석법
- **목적**: 임계값 주변에서의 처치 효과 추정
- **적용 영역**: 점수 기반 선발, 나이/소득 기준 정책, 등급 기반 인센티브

#### 유형
- **샤프 RDD**: 임계값에서 처치 확률이 0에서 1로 완전히 변경
- **퍼지 RDD**: 임계값에서 처치 확률이 급격히 변하지만 완전하지 않음

### 4. 성향 점수 매칭 (Propensity Score Matching, PSM)

#### 기본 원리
- **정의**: 처치 확률(성향 점수)이 유사한 관측치들을 매칭하여 비교
- **목적**: 선택 편향을 줄이고 관찰 데이터에서 인과 효과 추정
- **적용 영역**: 의학 연구, 마케팅 효과, 교육 프로그램 평가

#### 구현 단계
1. **성향 점수 추정**: 로지스틱 회귀 등을 통해 처치 확률 계산
2. **매칭 방법 선택**: 최근접 이웃, 칼리퍼, 커널 매칭 등
3. **균형 확인**: 매칭 후 공변량 분포의 유사성 평가
4. **처치 효과 추정**: 매칭된 샘플에서 결과 변수 비교

### 5. 기타 고급 실험 분석 방법

#### 도구 변수법 (Instrumental Variables, IV)
- **정의**: 결과에 직접 영향을 미치지 않고 처치에만 영향을 주는 변수 활용
- **목적**: 관찰되지 않은 혼동 요인이 있을 때 인과 효과 추정

#### 합성 대조법 (Synthetic Control Method)
- **정의**: 처치받지 않은 단위들의 가중 조합으로 대조군 구성
- **목적**: 단일 처치 단위와 여러 대조 단위가 있을 때 인과 효과 추정

#### 무작위 통제 시험 (Randomized Controlled Trials, RCT)
- **정의**: 참가자를 무작위로 실험군과 대조군에 배정하는 실험 설계
- **목적**: 가장 엄밀한 인과 관계 추정

### 6. 실험 분석 실무 지침

#### 사전 계획
- **사전 등록**: 결과 및 분석 계획 사전 명시
- **MDE 계산**: 최소 탐지 가능 효과 크기 산정
- **통계적 검정력 분석**: 필요 샘플 크기 결정

#### 결과 해석
- **다중 검정 조정**: 여러 지표 테스트 시 오류율 조정
- **이질적 효과 분석**: 하위 그룹별 효과 차이 탐색
- **효과 지속성 평가**: 단기 vs 장기 효과 비교
